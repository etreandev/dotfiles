* Font
doom exposes five (optional) variables for controlling fonts in doom:
- `doom-font':: the primary font to use
- `doom-variable-pitch-font':: a non-monospace font (where applicable)
- `doom-big-font':: used for `doom-big-font-mode'; use this for presentations or streaming.
- `doom-unicode-font':: for unicode glyphs
- `doom-serif-font':: for the `fixed-pitch-serif' face
#+begin_src emacs-lisp
(setq doom-font (font-spec :family "Monolisa" :size 25 :weight 'light)
      doom-big-font (font-spec :family "Monolisa" :size 30 :weight 'bold)
      doom-pitch-font (font-spec :family "Monolisa" :size 25)
      doom-variable-pitch-font (font-spec :family "Monolisa" :size 25)

* Theme
** Theme defaults
There are two ways to load a theme. Both assume the theme is installed
and available. You can either set `doom-theme' or manually load a theme with the
`load-theme' function. This is the default:
#+begin_src emacs-lisp
(setq doom-theme 'doom-monokai-ristretto)
#+end_src

This determines the style of line numbers in effect. If set to `nil', line
numbers are disabled. For relative line numbers, set this to `relative'.
#+begin_src emacs-lisp
(setq display-line-numbers-type 'relative)
#+end_src
